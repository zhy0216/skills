# 蓝紫手绘奇幻卡牌风格

复用用户于 2026-10-11 确认的视觉方向：粗墨线、硬边色块、蓝紫色分层环境，以及带古金细线和星空纹理的卡牌界面。原始游戏截图定义基础画风，用户认可的“悟空大战牛魔王”生成图展示换题材后的效果。

角色、世界观、动作和地点随用户需求替换。悟空、牛魔王、机械犀牛、水母、火焰山和蘑菇森林都是示例内容，不是风格的固定要素。

## 视觉特征

| 维度 | 保留的视觉方向 |
| --- | --- |
| 线条 | 深蓝黑色、粗重且不规则的外轮廓，少量断笔、干刷边缘和版画质感；内部结构线清楚。 |
| 上色 | 几何形硬边色块、赛璐璐阴影、概括的大块面；二维手绘质感。 |
| 造型 | 夸张而清晰的剪影、可辨认的装备与武器、明确的体型对比；细节集中在角色和关键道具。 |
| 配色 | 钴蓝、靛蓝、蓝紫主调；浅青远景与象牙白亮部；金色、红色、洋红或青色作局部焦点，按角色题材选择。 |
| 光效 | 小范围魔法辉光、明确的攻击轨迹和接触火花；保留墨线与角色结构。 |
| 环境 | 深色前景框景、清晰战斗中景、浅色雾化远景，形成舞台式纵深。 |
| 界面 | 深蓝星空底纹、古金细线、星盘圆弧、蓝红行动轨道、偏方形技能卡和清晰状态图标。仅在需要 HUD 时使用。 |

避免写实摄影、三维塑料材质、柔滑喷枪渐变、过度泛光、像素马赛克和宣传海报排版。背景细节不应压过角色。若用户要求更贴近原始截图，优先减少碎细节、加强大块面和不规则笔触；无需每次都沿用生成示例更密集的背景。

## 使用方式

1. 根据请求选择输出形式。只给出“甲打乙”这类战斗题材时，默认沿用参考图的 16:9 横版完整战斗截图，包含卡牌 HUD；角色立绘、场景图、无 UI 插画或其他比例则按用户要求构图，不强加战斗界面。
2. 先查看 `assets/style-reference.jpeg`；需要动作和界面示例时再查看 `assets/wukong-vs-bull-king.png`。将选中的图片作为**风格参考**传入生图工具，并说明只继承视觉语言，主体按本次需求重新设计。若用户另有编辑目标，明确区分目标图片与风格参考，并保留用户要求不变的部分。
3. 读取提示词模板，填入本次角色的辨识特征、武器、动作、场景和需要准确呈现的文字。仅加入适用模块，删除未填变量。用户指定的角色、题材、比例和输出形式优先。
4. 请求生成或改图时，默认使用内置 GPT 生图工具；环境提供 `imagegen` 技能时遵循其执行流程。将已查看的本地参考图路径传给支持参考图的接口。用户只要提示词时直接交付提示词，不额外生成。
5. 查看结果，重点检查角色辨识度、墨线与硬边块面、冷暖焦点、前中后景层次，以及动作中的肢体和武器；有 HUD 时同时检查中文、数字、卡牌完整性和遮挡。修改时围绕具体偏差调整。
6. 展示生成结果并保留最终提示词。输出有指定目录时保存到该目录；本技能的参考素材保持原样，新生成图不自动替换风格基准。
