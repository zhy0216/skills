# 可复用提示词

选用适合任务的模块，替换 `{{变量}}` 后再提交。变量是提示词参数，不要把花括号或未填字段发给模型。完整战斗图组合“通用风格”“战斗场景”和“游戏界面”；其他图片只使用通用风格与用户需要的构图。

```text

配色：以钴蓝、靛蓝、蓝紫为主，浅青与象牙白提供明亮区域，金色、红色、青色或洋红作少量点缀。结合主体本身的服装与材质选择点缀色。主体与背景保持清晰明度区分，魔法光效只在局部出现，轮廓和结构始终可辨。

避免写实摄影、3D 塑料材质、柔滑喷枪渐变、像素马赛克、过量泛光、水印、外部设备边框和画面黑边。
```

## 游戏界面（可选）

仅在用户需要完整游戏截图或延续已确认的战斗截图形式时加入。默认横向 16:9，底部 HUD 约占画面四分之一；技能数、文案、数值和图标依据本次题材填写。没有给定游戏规则时，使用少量合理的示意数值，避免让装饰性信息占据画面。

```text
完整游戏 HUD：顶部左侧是头像和角色名“{{角色名}}”；顶部中央显示场景名“{{场景名}}”和“{{回合文字}}”；右上角排列少量圆形资源图标与数字。角色脚下有细长血条、护甲和状态图标，敌人头顶显示攻击意图。

底部约四分之一是深蓝星空纹理操作栏，以克制的古金细线、星盘圆弧和少量贴合题材的装饰纹样点缀；上沿横向排列蓝红分段行动轨道。中央排列四张大小一致、完整可见的偏方形技能卡：古金卡角、蓝色发光边缘、深色卡面。卡面图标为{{四个与角色技能相关的简洁图标}}，带清晰费用数字。
右下角是黑底红环圆形按钮，文字准确写作“结束回合”。界面文字以{{语言}}呈现，文案短、图标清楚、层级明确，卡牌不遮挡角色。

整体呈现统一、可信的实际游戏战斗画面，避免巨大宣传标题和密集说明文字。
```

## 无 UI 或单个素材

用户要无 UI 插画时，删除整个“游戏界面”模块，补充“无文字、无血条、无卡牌、无按钮，完整展示主体与场景”。用户要立绘或图标时，改为相应构图，不沿用左右交战与前中后景要求。

用户要透明素材时，使用工具的透明背景能力，并在提示词中明确真正的透明背景、完整轮廓和干净边缘；不要绘制棋盘格来模拟透明。

## 根据反馈微调

- 更接近原始截图的粗粝感：减少背景碎细节，加强大块面，保留不规则墨线与干刷边缘。
- 更接近悟空示例的战斗感：强调体型差异、武器交会点和局部接触火花，保持人物与 HUD 清晰。
- 发光掩盖手绘质感：缩小光晕范围，恢复墨线、硬边阴影和非发光材质的暗部。
- 界面拥挤：缩短文案，减少状态图标和装饰密度，给角色、行动轨道与卡牌留出间距。
