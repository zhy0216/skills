# 拆图策略与提示词

## 单图拆分的目标

拆出的是能够运动的图层。只有原画中可见的像素可以直接保留；被手臂、衣物或另一条腿挡住的区域需要补画。输出仍沿用原图视角与静止姿态，避免在拆图时同时改成 T pose、正面或新比例。

把“是否需要独立运动”作为分件依据。例如：只做呼吸的头像可保持头部一整块；需要屈肘的手臂拆上臂和前臂，只有独立手势需求才继续拆手掌。头发、衣摆、武器按动作需求分层，不机械套用固定人形清单。

记录每件的 `id`、所属骨骼、左右含义、原图大致区域、连接关节、前后层级和补画内容。GPT 的识别结果和坐标需要通过回拼检查；需要精确轮廓时，用当前环境允许的分割工具或人工修正蒙版。

## 两种策略

### 逐部件提取与补全（默认）

1. 保留原图不变，为关键面部与服装纹理确定保留区。
2. 使用原图和当前部件的局部参考，输出该部件独立的透明素材。局部参考只标明范围，不把整块矩形背景当作有效部件。
3. 补齐关节附近被遮挡的部分，使相邻部件在中立姿势与目标弯曲范围内有重叠。重叠量随画风和动作决定，不固定为某个百分比。
4. 核对原图中的比例与角度，回拼后再处理下一处问题。每次生图都回带原始参考，避免只引用上一轮生成图导致累计漂移。

若工具链允许精确分割和合成，可将原始可见像素放在底图中，模型只负责缺失区域，最后把接受的补画区域合成回部件。保留区是否逐像素一致由实际合成和比较证明，不能只凭提示词声称。

默认使用内置 `imagegen` 编辑。需要用 Python/OpenCV 等执行图像裁切或合成时，遵循宿主工具规则及用户已经明确选择的处理方式；本技能不自行放宽这些限制。如果缺少精确工具，交付经过检查的生成提取稿，并如实标记为 `generated`，不标成无损提取。

### 整张部件摊开图（快速草稿）

指定完整部件清单、固定顺序、互不相碰和一致的相对比例，再逐件整理。生成式排版可能重排、缩放、漏件；摊开图中的位置不能充当角色原位坐标。

保留实际 alpha，并核对一件是否包含多个分离区域。连通域只能识别像素连接性，无法理解“头发装饰与头属于同一个部件”。按白色阈值去底会损伤白衣、眼白和高光，不作为默认抠图方法。部件定位与命名不能仅依赖连通域遍历顺序。

## 内置 GPT 图像工具的使用

读取当前环境的 `imagegen` 技能。查看本地原图后，按工具当前定义传递引用图片：都有路径时用文件引用；存在仅在对话中的图片时用最近图片引用。不要混用互斥的引用参数，不编造独立 mask、size 或 output-path 参数。

实际图像修改通过内置工具完成。需要模型/API 的专用参数时，先确认用户已经选择了该路径，再核实当前官方文档；不在这个技能中固定模型名称或过期参数。透明背景应保留到最终文件，生成目录里的文件要复制到项目内才可被场景引用。

### 单部件提示词示例

```text
用途：Godot 2D 骨骼动画的透明部件。
输入图 1：完整原画，是角色身份、画风与比例的依据。
输入图 2（如有）：目标部件的范围/局部参考，仅用于定位。
目标：提取角色自身左前臂，沿用原画中的朝向和透视。
保持：可见轮廓、袖口、纹理、线条粗细、配色和光照风格。
补全：肘部和腕部被遮挡的连接区域；留出被相邻部件覆盖的搭接部分。
构图：只放这一块完整部件，四周留安全边距，不切掉边缘。
输出：真实透明背景。不要文字、标尺、棋盘格底图或额外投影。
```

将部件和补全范围替换成实际分析结果；没有局部参考就删掉对应行。提示词中的保留要求属于目标，仍要检查输出是否发生重绘和漂移。

### 修正提示词示例

```text
输入图 1 是原画，输入图 2 是当前前臂部件。
修正图 2 的肘端：延长被上臂遮住的袖子连接区域。
保持前臂外形、手腕位置、服装图案、朝向及现有透明背景。
只调整肘端，继续输出完整独立部件。
```

## 校准与验收

- 在原图尺度下比较可见部分，关节标注明确使用角色左/右。画面左/右只是辅助描述。
- 裁紧、加边距、移动画布都会影响 PNG 左上角在原图中的坐标，必须同步更新 `image_origin`。
- 生成部件分辨率与原画不同，可用清单的 `texture_scale` 在 Godot 内等比校准；保留 PNG 的真实尺寸。透明边距在原图中也按该比例换算，不能把图像居中就当成关节已经对齐。
- 将补全纹理安排在原有遮挡层下面；不能为了遮住一个错误而改变脸、服装或身体比例。
- 观察深色和浅色背景上的边缘、白色部件、透明配饰和细小发丝。真实 alpha 与画出的棋盘格需要区分。
- 回拼图用于检查静止相似度；关节旋转预览用于检查接缝。这两项不能互相替代。
- 固定视角的切件不能凭一张原图保证大幅转身；需要新视角素材时说明具体缺口。

## 来源与能力边界

这是一套自定义流程，没有复制第三方非商业项目的代码或提示词。可参考其“先生成分离部件、再整理素材”的思路，但不要把连通域裁切理解为语义分割。

- [OpenAI 图像编辑与蒙版](https://developers.openai.com/api/docs/guides/image-generation#edit-an-image-using-a-mask)：蒙版是编辑引导，不能保证精确边界。
- [OpenAI 图像提示词](https://developers.openai.com/api/docs/guides/image-prompting)：参考图、透明输出、角色一致性和保留原图像素的合成策略。
